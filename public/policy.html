10. Groups (optional)

Groups is off by default. When you join a group, its other members can see your profile display name and the number of sets you logged in the last 7 or 30 days, broken down by event type (slalom, tricks, jump, other). They do not see set contents, individual set dates, scores, technique details or your notes. The breakdown by event type reveals which disciplines you train, which is why it is described here explicitly. Set counts include sets you logged before you joined, if they fall within the window. Leaving a group stops this sharing immediately.

Separately, a group's name and description are shown in the in-app directory to anyone signed in to iSkiLog, whether or not they are a member. Creating a group is a public act in that sense; joining one and appearing on its leaderboard is the part limited to members.

A group can be private. A private group still appears in the directory with a lock, but joining it requires a 6-digit code that an existing member shares with you. The code keeps people from wandering in; it is not a password and does not encrypt anything. A private group shares exactly the same data among its members as a public one.

Group names, group descriptions and profile display names are user-generated content and are governed by the User Content section of the Terms of Service above, including filtering, reporting, blocking and removal.
